# Moab Canyon Tours concept mockup

A standalone, conversion-focused concept for Moab Canyon Tours. The page includes an interactive booking-flow demo and the approved Singenuity explainer popup.

## Preview locally

Open `dist/index.html` directly, or serve the project folder with any static HTTP server.

## Build

Run `python3 build_mockup.py` to regenerate `dist/index.html`. The finished page is self-contained and does not depend on prospect-hosted media.

This is a concept website mockup, not the operator's production website.
